🍋 Little Lemon Restaurant API

Django REST Framework · MySQL · Token Authentication

Welcome

This application exposes menu and table-booking APIs.

  • Menu API — browse menu items
  • Bookings API — requires authentication
  • REST framework login
  • Django admin

Useful endpoints

POST /api/register/ create an account

POST /api-token-auth/ obtain an auth token

GET /api/users/me/ current user (token required)
